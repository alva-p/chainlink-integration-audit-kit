# Disclosure Policy

This project is an educational security toolkit. Reports about vulnerabilities in third-party protocols should be sent to those protocols through their published security contact, bug bounty program, or security policy.

## Reporting Issues In This Repository

Open a GitHub issue for:

- Incorrect scanner output.
- Broken examples or tests.
- Documentation errors.
- Missing checklist items.

Do not include live exploit details for an unpatched third-party protocol in public issues or pull requests.

## Responsible Disclosure Guidance

1. Preserve enough evidence to reproduce the issue.
2. Avoid interacting with live funds beyond what is necessary to confirm impact.
3. Contact the affected maintainers privately.
4. Give maintainers reasonable time to investigate and remediate.
5. Coordinate public disclosure only after a fix, mitigation, or agreed timeline.

If a protocol has an active bug bounty program, follow its rules.
